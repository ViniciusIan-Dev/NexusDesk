# Requisitos do NexusDesk

## 1. Objetivo

O NexusDesk tem como objetivo centralizar e organizar as solicitações de suporte técnico de uma empresa, permitindo acompanhar os problemas desde sua abertura até sua resolução.

## 2. Usuários do sistema

- **Solicitante:** pessoa que registra um problema técnico.
- **Técnico:** pessoa responsável por analisar e resolver os chamados.
- **Administrador:** pessoa responsável pela organização e administração do sistema.

## 3. Requisitos funcionais

- **RF01:** o sistema deve permitir cadastrar um chamado.
- **RF02:** o sistema deve permitir listar os chamados registrados.
- **RF03:** o sistema deve permitir consultar os detalhes de um chamado.
- **RF04:** o sistema deve permitir alterar o status de um chamado.
- **RF05:** o sistema deve permitir definir a prioridade de um chamado.
- **RF06:** o sistema deve permitir pesquisar chamados.

## 4. Requisitos não funcionais

- **RNF01:** o sistema deve validar os dados recebidos.
- **RNF02:** os dados devem permanecer armazenados após o encerramento da aplicação.
- **RNF03:** o código deve ser organizado para facilitar manutenção e testes.
- **RNF04:** erros devem ser tratados de forma clara, sem expor informações sensíveis.

## 5. Escopo inicial

A primeira versão será focada no gerenciamento de chamados. Cadastro de usuários, controle avançado de permissões e gerenciamento de equipamentos serão planejados para etapas futuras.

## 6. Status do projeto

Fase atual: definição dos requisitos e planejamento da primeira versão.

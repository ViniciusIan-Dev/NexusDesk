# NexusDesk
Plataforma de gestão de suporte técnico e ativos de TI, desenvolvida como projeto de estudo em engenharia de software.

## Sobre o projeto

O NexusDesk é um projeto de estudo em Engenharia de Software que tem como objetivo desenvolver uma aplicação para organizar solicitações de suporte técnico, acompanhar a resolução de problemas e gerenciar equipamentos de TI.

O projeto será desenvolvido de forma incremental, priorizando fundamentos de programação, organização do código, modelagem de dados, qualidade e boas práticas de desenvolvimento.

## Objetivos

- Centralizar chamados de suporte técnico.
- Acompanhar o status e a prioridade das solicitações.
- Organizar informações sobre equipamentos de TI.
- Aplicar conceitos de banco de dados e arquitetura de software.
- Praticar versionamento, testes e documentação técnica.

## Status do projeto

**Fase atual:** planejamento e definição dos requisitos.

As funcionalidades serão implementadas gradualmente, conforme o desenvolvimento avançar.

## Tecnologias

As tecnologias serão definidas durante a fase de planejamento, de acordo com os requisitos do projeto.
